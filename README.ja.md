# DaFeiYi · 大肥译 🐟

[リポジトリの構成とビルド手順（中国語・英語）](docs/repository-layout.md)：機能別のソースコードは `src/DaFeiYi/`、テストは `tests/`、ビルド・インストール用のスクリプトは `scripts/` にあります。ルートの `build.ps1` と `verify.ps1` も引き続き使用できます。

[简体中文](README.md) | [English](README.en.md) | **日本語**

論文を読んだり、用語を調べたり、数式を理解したりするときに、小さなクジラがそばにいてくれる Windows 用のフローティング翻訳ツールです。文字を選択して小さなボタンを押すと、翻訳や解説を表示します。自動翻訳やクリップボード翻訳に切り替えることも、クジラと一緒に過ごすこともできます。

[**Windows 版をダウンロード**](https://github.com/gary1110086/dafeiyi/releases/latest) · [**クイックスタート（英語）**](docs/getting-started.en.md) · [**問題を報告**](https://github.com/gary1110086/dafeiyi/issues/new/choose)

**DeepSeek の Web アカウント / API · 共通の読書ポップアップ · Markdown と数式 · 触れ合えるデスクトップのクジラ**

操作画面は Settings → Reading で簡体字中国語または英語を選べます。保存後に再起動してください。回答の言語は別に設定でき、中国語・英語・日本語に対応しています。この README は日本語版ですが、操作画面の日本語表示には対応していません。

![サンプルのデスクトップに表示した DaFeiYi の読書ポップアップとクジラ](docs/images/desktop-companion.png)

## 使い始める

1. [最新リリース](https://github.com/gary1110086/dafeiyi/releases/latest)から **DaFeiYi-Windows-x64-v1.1.2.zip** をダウンロードし、すべてのファイルを展開します。Source のアーカイブは開発者向けです。
2. **安装到桌面.cmd** を実行すると、デスクトップにショートカットを作成します。Windows へのサインイン時に自動起動する場合は **安装并开机启动.cmd** を実行してください。**轻译.exe** を直接起動することもできます。
3. **Settings → Connection & models** を開きます。Web アカウントを使う場合はアプリ内でログインし、接続状態を確認してから戻ります。Chrome のログイン状態は共有されません。API を使う場合は自分の API キーを入力してください。
4. 文を選択して **Translate / Explain** を押します。まずローカルで試す場合は **Settings → Getting started → Try selection demo** を開いてください。このデモにはアカウントも API も必要ありません。

| 使い方 | モード | 文字が送信されるタイミング |
|---|---|---|
| 必要なときだけ調べる | Button（ボタン） | Translate / Explain を押した後 |
| 続けて読み進める | Automatic（自動） | 文字を選択して少し待った後 |
| PDF などでコピーした文字を翻訳する | Clipboard（クリップボード） | 新しい文字をコピーした後 |
| クジラと一緒に過ごす | Companion（クジラのみ） | 自動での文字取得・翻訳は行いません |

クジラをクリックするとモードを切り替えられます。押したままドラッグすると移動します。クリップボードモードでは新しくコピーした文字を送信するため、私的な内容をコピーする前に Button または Companion に切り替えてください。

Windows 10/11 x64 と .NET Framework 4.8 に対応しています。Web モードには [Microsoft Edge WebView2 Runtime](https://developer.microsoft.com/microsoft-edge/webview2/) も必要です。新しい Windows / Edge 環境では通常インストールされています。Python、Node.js、Electron のインストールは不要です。

## デスクトップのクジラ

静かにそばにいてもらったり、頭をなでたり、token のおやつをあげたりできます。クジラだけを表示したい場合は、右クリックして **仅陪伴 · 关闭划词**（クジラのみ・選択翻訳をオフ）を選びます。

![待機中、頭をなでたとき、token を食べたときのクジラ](docs/images/pet-interactions.png)

画面の左端または右端にドラッグすると、体を隠して頭だけをのぞかせます。マウスを近づけると滑らかなアニメーションで現れ、離すと再び隠れます。

![画面右端から顔を出し、現れて再び隠れる連続アニメーション](docs/images/edge-peek.gif)

これらのプレビューは、このバージョンのキャラクター画像、画面端のアニメーション処理、ポップアップのスクリーンショットを、サンプルのデスクトップと合成したものです。個人のデスクトップやアカウント情報は含まれません。クジラとの触れ合いはローカルで動作し、モデルへのリクエストや API の使用は発生しません。

## v1.1.1 の変更点

- クジラのどこでもクリック、または右クリックするとメニューを開けます。4 種類のモードはメニュー上部にあります。押したままドラッグして移動できます。
- モード、読書ツール、履歴と用語、クジラとの触れ合い、表示設定を分類しました。通知領域のメニューも同じ順序です。
- モードを選択すると文字の検出を再開し、以前の一時停止状態が残って動作しないことを防ぎます。Companion モードでは自動翻訳を行いません。
- 設定から Chrome で Web サイトを開けます。Chrome がない場合は既定のブラウザーを使います。この補助機能のログイン状態はアプリ内とは別です。
- **Settings → Updates & about → Check for updates → Save & update** で、ダウンロード、検証、プログラムファイルの置換、再起動を行います。置換に失敗した場合は以前のファイルに戻し、ユーザーデータは削除しません。

外部ブラウザーでのログインをアプリにつなぐには、コールバックを伴う認証フローやブラウザー拡張が必要です。公式の [DeepSeek Harness](https://github.com/deepseek-ai/deepseek-harness/blob/master/packages/credentials/deepseek-account-platform/README.md) は、推論 API の利用にプラットフォーム認証と PKCE コールバックを使います。チャット Web サイトのセッションとは異なり、無料の Web チャットと同じものではありません。現在の DaFeiYi はアプリ内で Web アカウントにログインします。アカウントのウィンドウを閉じてもセッションは保持されます。

### 更新時のローカルデータ

API 設定、Web セッション、直近 30 件の履歴、保存した用語、取り込んだ背景は、プログラムファイルとは別の `%LOCALAPPDATA%\LightTranslate` に保存されます。更新時はこのディレクトリ、ショートカット、自動起動設定を保持します。更新の確認では公開 GitHub に接続し、個人設定は送信しません。ダウンロードの SHA-256 とパッケージ内のファイル一覧を検証し、置換したファイルはバックアップします。

v1.1.0 以前から初めて更新する場合は、新しいパッケージをダウンロードしてすべて展開し、**安装到桌面.cmd** または **安装并开机启动.cmd** を実行して上書きインストールしてください。アンインストールは不要です。ユーザーデータのディレクトリは残してください。v1.1.1 以降は設定画面から更新できます。別のコンピューターへの移行は別途必要で、Windows で暗号化された API 認証情報やブラウザーのセッションを、別アカウントでそのまま使えるとは限りません。

## v1.1 の変更点

- Web サイトの入力欄やボタンを、表示されている入力要素と中国語・英語の意味に基づいて検出します。通常の翻訳では、思考モードの切り替えに依存しなくなりました。
- ログイン操作で Web モードに切り替わります。アプリ内でログインしたら **Done signing in · return** を押してください。**Check website** はページの準備状態を確認するだけで、質問を送信しません。
- 失敗時も原文、現在の切り抜き画像、追加質問を保持します。**Check website / sign in** と **Retry this request** で対処できます。Web サイト上の未送信の文章や添付ファイルは保持し、自動で API に切り替えません。
- **Ctrl+Alt+S → Image / formula**：範囲を選択してプレビューを確認し、数式の解説、グラフの分析、文字の読み取りと翻訳を選べます。文字 OCR に限らず画像の内容を理解しますが、不鮮明な部分や切り抜きで失われた情報によって誤りが生じることがあります。
- API による画像理解では、既定で **deepseek-flash** を使います。Web モードでは自分のアカウントの画像アップロード機能を使います。機能、制限、料金は各サービスによって異なります。
- 操作画面と回答の言語を個別に設定できます。初回向けのローカル選択デモと、設定内の最新リリースへのリンクを追加しました。
- 新しいリリースのインストーラーで更新しても、認証情報、ログイン、履歴、保存した用語はユーザーデータの場所に残ります。

## 機能

- ボタンで翻訳、自動翻訳、クリップボード翻訳、クジラのみの 4 モード。選択ボタンには専用のドラッグ用ハンドルがあります。
- DeepSeek の Web アカウントと API に対応し、素早い回答と深い思考を切り替えられます。
- Markdown の見出し、リスト、コード、表、LaTeX 数式をローカルで表示します。
- 移動、サイズ変更、固定ができるポップアップ。固定していないときは別のアプリをクリックすると隠れます。回答生成中に閉じるとリクエストをキャンセルします。
- 現在の文章への追加質問、直近 30 件の完了した履歴、用語の保存、個人メモ、よく使う訳語。
- 2 種類の内蔵背景、独自の背景、文字サイズと行間の調整。
- 頭をなでる、尾を動かす、token をあげる、ドラッグする、画面の左右端から顔を出すアニメーション。これらの操作はモデルにリクエストを送りません。

| ショートカット | 操作 |
|---|---|
| Ctrl + Alt + D | 選択した文字を取得。直接取得できない場合はコピーを試みます |
| Ctrl + Alt + V | クリップボードにコピー済みの文字を翻訳 |
| Ctrl + Alt + S | 文字 OCR、または数式・グラフ・画像の範囲選択 |
| Esc | 結果を閉じる |
| Ctrl + E | コンパクト表示と展開表示を切り替える |

選択した文字を取得できるかどうかは、元のアプリが選択情報を公開しているかに依存します。取得できない場合は、コピーや画面の OCR を使ってください。OCR の結果は編集できます。数式や複数列の文章は正しく認識されない場合があります。

## Web モードで翻訳できない場合

1. **Website account** を選択し、**Use website / sign in** を押します。ログインはアプリ内で完了してください。外部ブラウザーのログインとは別です。
2. 必要な認証を完了し、**Done signing in · return** を押します。設定画面にページの準備状態が表示されます。
3. ポップアップの **Retry this request** を押します。Web サイト上に未送信の文章がある場合は、先にアカウントのウィンドウで処理してください。
4. それでも失敗する場合は **Export diagnostics** を使い、表示されたエラーを添えて報告してください。パスワード、Cookie、API キーは不要です。

## プライバシーと接続

**配布パッケージに、開発者の API キー、ログインセッション、個人設定、履歴、保存した用語、独自の背景は含まれません。各自のアカウントを使用します。**

- 個人データはローカルの `%LOCALAPPDATA%/LightTranslate/` に保存します。API キー、履歴、保存した用語は、現在の Windows ユーザーの認証情報で暗号化します。
- Web ログインには独立した WebView2 プロファイルを使います。アカウントのパスワードを読み取ったり、Cookie をエクスポートしたりしません。必要な認証は Web サイト上で自分で完了してください。
- 文字 OCR はローカルで動作します。画像理解では、確認後の切り抜き範囲だけを送信し、画面全体はアップロードしません。画像への追加質問では、現在の切り抜きと会話の文脈を再送信します。切り抜きはセッションのメモリ内に保持し、履歴にはラベルと回答だけを保存します。画像データは履歴に保存しません。
- エクスポートする接続診断は状態と WebView2 のバージョンだけを含み、アカウント、Cookie、キー、原文、チャットは含みません。
- 自動モードとクリップボードモードでは対象の文字を処理のために送信します。用途に合うモードを選んでください。API の料金は自分のアカウントに計上されます。
- Web アカウントモードは Web セッションを通じて動作するため、Web サイトの変更に合わせた更新が必要になる場合があります。失敗しても有料 API に自動で切り替わりません。

## ビルドと検証

ソースコードをダウンロードしたら、そのディレクトリで次を実行します。

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\build.ps1
```

ビルドには Windows に付属する .NET Framework の C# コンパイラー（`csc`）を使います。依存ライブラリ、フォント、アニメーション画像、ライセンスはリポジトリに含まれています。

ローカルの検証には `verify.ps1` を実行してください。ローカルの模擬サービスを使うため、本物の API キーは不要です。テストでは一時的にウィンドウを作成し、マウスを動かします。

実際の画像接続テストは `--vision-connect-test <output-directory> web|api` を明示的に実行します。生成した図形画像を送信します。API テストには少額の利用料金がかかり、通常の検証には含まれません。

実際の Web アカウントの接続テストも `--web-connect-test <output-directory>` の明示的な実行が必要です。自分の Web アカウントを通じて短いテスト質問を送信します。通常の検証スクリプトから自動で実行されることはありません。
